# First Pull

Y'all need to install packeages first
run:

```bash
bun intall
```

or

```bash
bun i
```

pls check Bun is exist and installed in your environment
if you not have bun install it with :

**MAC**

```bash
curl -fsSL https://bun.sh/install | bash
```

**WINDOWS**

```bash
powershell -c "irm bun.sh/install.ps1 | iex"
```

more details in :
https://elysiajs.com/quick-start
